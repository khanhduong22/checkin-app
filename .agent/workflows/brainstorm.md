# Brainstorm Workflow

## Steps

1. **Clarify the Core Objective**:
   - What user problem are we solving?
   - What are the business and system constraints?
2. **Explore Technical Approaches**:
   - Compare Tradeoffs (Pros vs Cons table).
   - Verify performance and scalability impact.
3. **Formulate High-Level Architecture**:
   - Define data model changes and API contracts.
   - Present plan to user for alignment.
